# PeakRush display headings

The three homepage headings use a local subset of Smiley Sans (得意黑),
an oblique display face designed by atelierAnchor.

Source: https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1

`PeakRushDisplay-Regular.woff2` was produced from the official
`SmileySans-Oblique.ttf` release using `fontTools.subset`, retaining
准、点、开、抢、限、时、好、物 and space.
Its internal family, style, unique and PostScript names were changed to
PeakRush Display to respect the original font's reserved names.
The original letterforms and their built-in slant are preserved.

License: SIL Open Font License 1.1; see `PeakRushDisplay-LICENSE.txt`.
Only the bundled WOFF2 is loaded at runtime; no external font service is used.
